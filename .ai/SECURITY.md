# Security: voice

**Last reviewed:** 2026-10-31. The repo is a kit: scripts that read a principal's local history and
write paraphrase, and Voice, the app growing around them. Nothing here runs as a service or
opens a network port. Voice makes two kinds of network call: its saving code
(`builder/save/`), which talks to GitHub alone, and its model-server provider
(`builder/agent/src/self_hosted.rs`), which talks only to an address on this computer or the
person's own network. Reporting: `SECURITY.md`.

## What could go wrong

- A real person's data reaches a commit: a member folder, a name, a quote, a Slack id.
- A principal's raw history is written somewhere other than their state or work folder.
- A crafted export (oversized zip, odd file names, crafted JSON) crashes a miner or escapes its folder.
- A voice recording is committed.
- Someone's assistant is pushed to a public repo, or to a repo nobody confirmed is private.
- A GitHub sign-in token leaks: into a file, a log, a command line or an error message.
- A password or key file (`.env`, `~/.ssh/`, a `.pem`) is read into a history, a model's brief or a
  saved assistant.
- A brief carries data to a model provider the person did not allow for that data (mail sent to
  Anthropic when the person keeps it on their own machines).
- A brief meant for the person's own model server reaches an address outside their machines: a
  name that resolves to a public address, a proxy, a redirect.

## Controls

| A copy of the app is swapped or damaged on its way to someone | Against a swap: the build writes the zip's SHA-256, sent in a separate message that says to check it first, and step 3 of `How to install.txt` has the person compare it before running anything from the zip (the installer and the how-to travel in the zip, so neither can vouch for itself). Against damage: the copy is ad-hoc signed and the installer checks the signature (`codesign --verify --deep --strict`) before and after copying. The installer clears the download quarantine only on its own copy in `~/Applications` (the strict check refuses a symlink that leaves the bundle), asks for no password, and refuses a copy for the other chip; the build runs only from a git checkout and refuses uncommitted sources.
