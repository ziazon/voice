# VO11.1a brief: the egress proxy

VO11 found that Seatbelt can't name hosts, only a port on this computer, so the sandboxed `claude`
child reaches the internet through a proxy the app runs (`docs/spikes/VO11-os-sandbox.md`, *The
answer* 3). VO11.1b landed the launch library (`builder/agent/src/sandbox.rs`), which takes the
proxy's port as a number and sets `HTTPS_PROXY=http://127.0.0.1:<port>`. This slice lands **the
proxy itself**: `builder/agent/src/egress.rs`, a Rust HTTP `CONNECT` proxy, one per `claude`
launch. It is the only network control the child has, so treat every rule below as a security
boundary. It is **not** wired into `claude.rs`, `sandbox.rs` or any caller: that is VO11.1c.

`docs/spikes/VO11-os-sandbox.md`, and the probe's Python proxy (`EgressProxy` in

## 1. The public surface

In `builder/agent/src/lib.rs` add `pub mod egress;` (alphabetical, after `child`). In `egress.rs`:

```rust
/// One running proxy. Dropping it stops it.
pub struct Egress { /* private */ }

impl Egress {
    /// Listens on 127.0.0.1, on a port the system picks, with the rules for Claude Code.
    pub fn start() -> Result<Egress>;
    /// The port to hand to the sandbox (`sandbox::Launch`'s proxy port).
    pub fn port(&self) -> u16;
    /// Closes the listener and every connection, and joins every thread it started.
    pub fn stop(self);
}
impl Drop for Egress { /* the same stop, idempotent */ }
```

Nothing else is public. `start()`'s only failure is the bind (or the accept thread failing to
spawn): map it to `Error::Io { path: PathBuf::from("127.0.0.1"), source }`. No new `text::`
sentence: nothing here is shown to a person.

## 2. The rules (private, one struct, so tests can shorten the clocks)

```rust
struct Rules {
    hosts: &'static [&'static str],      // ["api.anthropic.com", "platform.claude.com", "claude.ai"]
    resolve: fn(&str) -> io::Result<Vec<IpAddr>>,
    public: fn(IpAddr) -> bool,
    upstream_port: u16,                  // 443
    header_time: Duration,               // 10 s
    header_bytes: usize,                 // 8 * 1024
    connections: usize,                  // 16
    dial_time: Duration,                 // 10 s
    idle: Duration,                      // 5 * 60 s
}
fn start_with(rules: Rules) -> Result<Egress>;   // start() == start_with(Rules::claude_code())
```

`Rules::claude_code()` is the only production value. The hosts were checked against Claude Code
2.1.292's binary (the token at `platform.claude.com/v1/oauth/token`, the roles at
`api.anthropic.com/api/oauth/claude_cli/roles`); the sign-in page on `claude.com` is opened by the
browser, never the child, so `claude.com` is **not** in the list. Put that sentence in the doc
comment on the list.

The production resolver is `(host, 443).to_socket_addrs()` mapped to its IPs. The `CONNECT`
target must still say port 443; `upstream_port` is only the port dialled, so a test can point it at
a local fake server.

## 3. One connection, step by step

Each accepted connection gets one handler thread. In order:

1. **The slot.** If `connections` connections are already open (from accept until both directions
   end), write `HTTP/1.1 503 Service Unavailable\r\n\r\n` and close it, from the accept thread,
   without starting a thread. A slot is held from accept until the handler thread ends.
2. **The request.** Read into one buffer until it holds `\r\n\r\n`, with one deadline of
   `header_time` from accept (each read's timeout is the time left; never a fresh 10 s per read).
   More than `header_bytes` bytes before the terminator: `400`, close. Deadline passed: close
   without an answer. The peer closed: close. Bytes after the terminator are the start of the
   tunnel: keep them and send them upstream first, after the dial.
3. **Parse, strictly.** Lines end in `\r\n` only. The request line is exactly three words split
   by single spaces: method, target, version.
   - method not `CONNECT` (case-sensitive, RFC 9110 § 9.1): `405 Method Not Allowed`;
   - version not `HTTP/1.1` or `HTTP/1.0`, or any other malformed line: `400 Bad Request`;
   - target must be `<host>:443` with `host` ASCII letters, digits, `.` and `-` only, compared
     to the list ignoring ASCII case (RFC 3986 § 3.2.2). No trailing dot, no user info, no IP
     literal, no other port, no percent-encoding: `403 Forbidden`.
   - Headers are not interpreted; they only count toward the size.
4. **Resolve and check, before dialling.** Resolve the host **once**, bounded by `dial_time`
   (resolution and dialling share one deadline): run `resolve` on a short-lived helper thread
   and wait on a channel with `recv_timeout`. A helper that outlives the deadline is abandoned
   (it holds no socket; say so in a comment), and is the only thread `stop()` does not join.
   If the answer is empty, or **any** address fails `public`: `403`, close. Never resolve again:
   dial the checked addresses (each with `TcpStream::connect_timeout` and the time left, in the
   resolver's order, the first that connects wins). All failed or timed out: `502 Bad Gateway`.
5. **Tunnel.** Write `HTTP/1.1 200 Connection Established\r\n\r\n`, send the kept bytes, then
   copy both ways: the handler thread copies child to upstream and starts one more thread for
   upstream to child. Both share the time of the last byte in either direction (an `AtomicU64`
   of milliseconds since the connection's `Instant`). Each read's timeout is `idle` minus the
   time since that last byte (at least 1 ms); when a read times out and nothing has moved for
   `idle`, shut both sockets down. When either side ends (EOF or error), shut both down so the
   other copy ends too. Every write is a full write (`write_all`).

All answers are the status line plus `\r\n\r\n`, nothing else. Never echo the request back.

## 4. `public(ip)`

A new private `fn public(ip: IpAddr) -> bool` in `egress.rs`: **an allow list, not a deny
list**. Cite the IANA special-purpose registries in its doc comment
(`https://www.iana.org/assignments/iana-ipv4-special-registry/` and
`https://www.iana.org/assignments/iana-ipv6-special-registry/`).

- IPv4 is public unless it is in `0.0.0.0/8`, `10.0.0.0/8`, `100.64.0.0/10`, `127.0.0.0/8`,
  `169.254.0.0/16`, `172.16.0.0/12`, `192.0.0.0/24`, `192.0.2.0/24`, `192.88.99.0/24`,
  `192.168.0.0/16`, `198.18.0.0/15`, `198.51.100.0/24`, `203.0.113.0/24`, `224.0.0.0/4` or
  `240.0.0.0/4` (which holds `255.255.255.255`).
- IPv6: an IPv4-mapped address (`::ffff:0:0/96`) is judged as its IPv4 address. Otherwise it is
  public only inside `2000::/3`, and not inside `2001::/23`, `2001:db8::/32` or `2002::/16`.
  Everything else (`::`, `::1`, `fc00::/7`, `fe80::/10`, `ff00::/8`, `64:ff9b::/96`, `::/96`)
  is not public.

Do not reuse or change `self_hosted::own_network`; it answers a different question.

## 5. `stop()`

Set a stopped flag; wake the accept thread (connect once to its own port, which it then drops);
join it; shut down (`Shutdown::Both`) every socket the proxy holds (the children's from accept,
the upstreams' from the dial, kept in one `Mutex` registry and removed when a connection ends);
join every handler and copy thread. A handler that finds the flag set after a step (after the
read, after the dial) closes at once. A dial already under way finishes within its deadline,
so `stop()` returns within about `dial_time` at worst; say so in its doc comment. Calling it
twice, or dropping after it, does nothing more.

3. Refused with `403`: `example.com:443`, `claude.com:443`, `api.anthropic.com:80`,

   no connection.
4. `GET http://api.anthropic.com/ HTTP/1.1` gets `405`; `connect …` (lower case) gets `405`;
   `CONNECT api.anthropic.com:443 HTTP/2.0`, two spaces between words, a bare `\n` line end, and
   a missing version get `400`.
5. A request of more than `header_bytes` with no terminator gets `400`; one exactly at the limit
   (terminator included) gets `200`.
6. A client that sends half a request and waits: closed with no answer after `header_time`, not

## 10. Fixes after the security review and the Verifier

The Verifier passed the build (17 tests green 12 times at 16 and 32 threads under load; no
escape found). The security review failed it on one MEDIUM, measured, which the Verifier also
raised: **`stop()` can hang forever.** It wakes the accept thread with one `connect` and ignores
the result; when the app is out of file descriptors (the reviewer filled the table with
`setrlimit` and `/dev/null` files) the connect fails, `accept.join()` never returns, and since
the sockets are shut down only after that join, nothing frees a descriptor. Measured: 6
descriptors per open tunnel, and apps started by launchd get a soft limit of 256. Change only
what this section names.

1. **`stop()` in this order:** set the stopped flag; shut down every registered socket (so the
   handlers end and drop their descriptors); then, until the accept thread has finished, try the
   wake connection with `TcpStream::connect_timeout` of 100 ms, waiting 10 ms between tries;
   join the accept thread; shut down every registered socket **again** (one accepted just before
   the flag may have been registered after the first sweep); join the handlers. Update its doc
   comment. **Test, red first:** a new integration test file
   `builder/agent/tests/egress_descriptors.rs` (its own process, so lowering a limit can't
   disturb other tests), using only `Egress::start()`: open 4 clients that each send half a
   request, lower the soft `RLIMIT_NOFILE` to the number of descriptors now open plus a few
   (`libc::getrlimit`/`setrlimit`; this test may use `unsafe` for those two calls only, each
   with a `// SAFETY:` line), open `/dev/null` until `open` fails with `EMFILE`, then call
   `stop()` on a thread and assert it returns within 3 s. Close the fillers and restore the limit
   at the end. Mark it with the existing skip style only if you can show it can't run; it should
   run anywhere on macOS and Linux.
2. **A failed `accept` waits 10 ms before the next try** (persistent `EMFILE` would otherwise
   spin a core). `thread::sleep` on that error path only.
3. **`header()` retries `Interrupted`** like `tunnel()` does, instead of closing.
4. **`3fff::/20` is not public** (RFC 9637, documentation; in the IANA IPv6 registry as not
   globally reachable). Add it to the IPv6 rule and keep `public_ranges`' row for
   `3fff:ffff:ffff:ffff:ffff:ffff:ffff:ffff` (outside the /20, still `true`); add `3fff::`
   (false), `3fff:fff:ffff:ffff:ffff:ffff:ffff:ffff` (false), `3fff:1000::` (true) and
   `3ffe:ffff:ffff:ffff:ffff:ffff:ffff:ffff` (true) as boundaries.
5. **NAT64's well-known prefix `64:ff9b::/96` is judged by its IPv4 address**, like the mapped
   form (IANA lists it as globally reachable; on a DNS64 network every answer is in it, so
   refusing it would leave Claude Code with no network). Only `/96`; `64:ff9b:1::/48` (local use)
   stays not public. Table rows: `64:ff9b::101:101` (1.1.1.1) true, `64:ff9b::a00:1` (10.0.0.1)
   false, `64:ff9b:1::1` false.
6. **Cap the resolvers in flight.** A shared counter of resolver helper threads still running;
   when it is at `connections`, answer `502` without starting another. The helper decrements it
   when `resolve` returns, abandoned or not. Reword the comment: an abandoned resolver holds none
   of the proxy's sockets. **Test, red first:** with a resolver that sleeps 2 s and counts its
   calls, `dial_time` 100 ms and `connections` 2, send three CONNECTs one after another: the
   first two get `502` after their dial time, the third gets `502` at once, and the resolver was
   called exactly twice.
7. **The racy asserts.** In `stop_and_drop_join_and_close_everything`, delete the two
   `assert!(TcpStream::connect(("127.0.0.1", port)).is_err())` lines (a freed port can be taken
   by another test's `bind(0)`; the Verifier measured 1 failure in 15 runs). The joined accept
   thread and the EOFs already prove the stop.
8. **Nits.** Import `AtomicUsize` instead of spelling out `std::sync::atomic::AtomicUsize`; one
   comment at the host check saying the byte and trailing-dot checks are a second line behind
   the exact list compare.
