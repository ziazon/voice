# VO10.3 brief: Panels on the app's screen

A panel is several of one person's AI assistants working one question out in rounds and coming
back with a joint proposal, plus the dissent of any who would not agree. VO10.1 landed the rules
(`builder/panels`), VO10.2 the runner and the app-facing functions (`builder/panel-runner`,
`builder/api/src/panels.rs`, DTOs in `builder/api/src/dto.rs`, TypeScript types already generated
in `builder/ui/src/types/generated/Panel*.ts`, `ConvenePanelRequest.ts`, `ResumePanelRequest.ts`).
This slice puts Panels on the app's screen: start a panel (the question, the kind of answer, which
assistants sit, a time limit), watch its rounds, stop it, answer its time question, carry it on,
and read the result: the answer, the groups and every dissent quoted in full. **Every word that
came from a model is shown as plain text, never as HTML.**

Read first: `AGENTS.md`, `.ai/PROJECT.md`, `.ai/SECURITY.md`, `CONTRIBUTING.md`,
`plans/briefs/VO10.2-panel-runner.md`. Skills: `~/.codex/skills/tdd-skill/SKILL.md`,

## Sources (checked 2026-10-30)

- **The API to wire**: `builder/api/src/panels.rs`: `convene_panel(ConvenePanelRequest, &mut
  dyn FnMut(PanelProgress)) -> Result<PanelRan, Failure>`, `resume_panel(ResumePanelRequest,
  progress)`, `stop_panel(PanelIdRequest) -> Result<()>`, `list_panels() -> Result<Vec<PanelSummary>>`
  (newest first), `panel(PanelIdRequest) -> Result<PanelDetail>`.
- **The pattern for a long command with progress and stop**: `builder/app/src/commands.rs`
  `build_assistant` / `stop_build` (a `tauri::ipc::Channel<…>` argument named `on_progress`),
  and on the screens `builder/ui/src/screens/build/BuildRun.vue` (running, stopping, lines,
  `failureMessage`), `builder/ui/src/app/tauri-backend.ts` `buildAssistant` (a `Channel` with
  `onmessage`).
- **The command lock-down**: `builder/app/src/command_names.rs` (`COMMANDS`), `src/main.rs`
  (`generate_handler!`), `capabilities/default.json`, `permissions/autogenerated/*.toml`
  (written by `tauri_build` when the app crate builds; commit what the build writes),
  `builder/api/src/parity.rs` (`PARITY`), `builder/app/tests/lockdown.rs`,
  `builder/cli/tests/app_parity.rs`.
- **What the runner's words and states are** (`builder/panel-runner/src/run.rs`, `text.rs`):
  - status: `running`, `paused` (it asked how long they may take and waits for the answer),
    `stopped`, `failed`, `closed`.
  - result outcome: `agreed`, `deadlock`, `open` (the time limit ran out first).
  - time limit: none (it asks after about five minutes and pauses), `15m`, `1h`, `deadlock` (no
    limit: until they agree or get stuck).
  - kind: `text`, or `list:1` … `list:12`.
  - seats: 2 to 24 different assistants, each needing permission given and a finished build.
  - question: 1 to 200 characters; background at most 4096 bytes.
  - withheld findings words: `email`, `path`, `term`, `private`, `secret`.
  - `resume` with `timeBox` answers the time question (only when `detail.asked` and the status
    is `paused`); with neither `timeBox` nor `steer` it carries on a `stopped`, `failed` or
    crashed (`running` on disk, not running here) panel; with `steer` it reopens a `closed`
    panel ("ask them to reconsider"). A `closed` panel without a steer is refused.
  - every failure reaches the screens as `{ message }` (`Failure`); show it only through
    `failureMessage(error, fallback)` from `builder/ui/src/failure.ts`.

## Part 1: the app's commands (Rust)

1. `builder/app/src/commands.rs`: five `#[tauri::command(async)]` functions, each a thin call,
   named exactly as below and shaped like `build_assistant` / `stop_build`:
   - `convene_panel(request: ConvenePanelRequest, on_progress: Channel<PanelProgress>) ->
     Result<PanelRan, Failure>`

     Result<PanelRan, Failure>`
   - `stop_panel(request: PanelIdRequest) -> Result<(), Failure>`
   - `list_panels() -> Result<Vec<PanelSummary>, Failure>`
   - `panel(request: PanelIdRequest) -> Result<PanelDetail, Failure>`
2. Append the five names, in that order, at the end of `COMMANDS`, of `generate_handler!` in
   `main.rs`, of `capabilities/default.json` (`allow-convene-panel`, `allow-resume-panel`,
   `allow-stop-panel`, `allow-list-panels`, `allow-panel`) and of `lockdown.rs`'s expected list.
   Build the app crate once so `tauri_build` writes the five `permissions/autogenerated/*.toml`.
3. `PARITY` rows, in the same order: `convene_panel` → `[["panel","convene"]]`; `resume_panel`
   → `[["panel","resume"]]`; `stop_panel` → `[["panel","convene"],["panel","resume"]]` (the CLI
   stops with Ctrl-C, as `stop_build` → `["build"]`); `list_panels` → `[["panel","list"]]`;

## Part 3: the screens (Vue 3, Tabler classes, matching the neighbours)

New files; keep each to one job, as the neighbours do:

- `builder/ui/src/screens/panels/words.ts`: pure functions, the only place these words live:
  - `statusWords(status: string, round: number): string` →
    `running`: `Running: round {round}.`; `paused`: `Waiting for you: how long may they take?`;
    `stopped`: `Stopped after round {round}. You can carry on from here.`; `failed`:
    `It stopped on a problem after round {round}. You can try again from there.`; `closed`:
    `Finished after round {round}.`; anything else: `This panel's state couldn't be read.`
    (For round 0 say `before the first round` in place of `after round 0` / `round 0`.)
  - `outcomeWords(outcome: string): string` → `agreed`: `They agreed.`; `deadlock`:
    `They couldn't agree.`; `open`: `Time ran out before they agreed.`; else
    `This result's outcome couldn't be read.`
  - `findingWords(finding: string): string` → `email`: `an email address`; `path`:
    `a file or folder location`; `term`: `a private word`; `private`: `something personal`;
    `secret`: `something that looks like a password or key`; else `something private`.
  - `TIME_LIMITS`: `[{ value: null, label: 'Ask me after five minutes' }, { value: '15m',
    label: '15 minutes' }, { value: '1h', label: 'An hour' }, { value: 'deadlock', label:
    'No limit: until they agree or get stuck' }]`.
- `builder/ui/src/screens/panels/PanelResult.vue`: props `{ result: PanelResultView }`.
  - Heading `Their answer`, then `A proposal for you, not a decision.`, then
    `outcomeWords(result.outcome)`.
  - The answer: `answerText` in one block element; or `answerItems` as an `<ol>`; neither:
    `They gave no answer.`
  - `How they grouped`: per group, the members joined by `, `, then
    `{Math.round(weight * 100)}% of the panel`, then its answer (text or `<ol>`).
  - `Who disagreed`: per dissent, the assistant's name, `Held out to the end.` when `holdout`,
    then the objections **in full** in a `<blockquote>` (never cut, never "show more"). No
    dissent: `Nobody disagreed.`
  - A `<details>` with `<summary>The whole result as text</summary>` and the `markdown` in a
    `<pre>` (shown as the raw text, never rendered).
  - Every model-written string (answers, items, objections, markdown) sits in an element with
    `class="text-break"` and `style="white-space: pre-wrap"`, so a 1,500-character word wraps
    and line breaks show.
- `builder/ui/src/screens/panels/NewPanel.vue`: emits `start: [ConvenePanelRequest]`, `cancel: []`.
  - On mount `listAssistants()`: loading line `Loading your assistants…`; error via
    `failureMessage(…, "Your assistants couldn't be read. Close Persona Builder and open it again.")`;
    fewer than two assistants: `Make at least two assistants first. A panel needs two or more.`
  - `The question` (input, `maxlength` not set; a counter `{n} of 200 characters`, the count is
    `[...text.trim()].length`), `Anything they should know (optional)` (textarea; a counter in
    bytes via `new TextEncoder().encode(text).length`, `of 4096`).
  - `The kind of answer`: radios `One written answer` (`text`) and `A list` with a number input
    `How many items` (1 to 12, default 3; `v-model.number`) → `list:{n}`.
  - `Who sits on the panel`: one checkbox per assistant, labelled with its `name`; an assistant
    without permission (`consent.agreed` false) is disabled with `Needs your permission first`.
  - `How long they may take`: radios from `TIME_LIMITS`, default the first.
  - The note: `Each assistant's turns use your Claude plan and count toward that assistant's daily limit.`
  - `Start the panel` (primary) is disabled until the trimmed question is 1 to 200 characters,
    the background at most 4096 bytes, the list size an integer 1 to 12, and 2 to 24 assistants
    are ticked. It emits `{ question: trimmed, background, kind, seats: ticked slugs in the
    listing's order, timeBox }`. `Cancel` (link button) emits `cancel`.
- `builder/ui/src/screens/panels/PanelRun.vue`: props `{ id: string | null, start:
  ConvenePanelRequest | null }` (exactly one is set); emits `running: [boolean]`, `back: []`.
  - With `start`: on mount call `convenePanel(start, onProgress)`. With `id`: on mount
    `panel({ id })` (loading line `Loading the panel…`; error via `failureMessage(…, "This panel
    couldn't be read. Try again.")`).
  - While a call runs: `running` true (emit it), the progress lines in an `aria-live="polite"`
    list as `BuildRun.vue` shows them, `Stop for now` (outline danger) → `stopPanel({ id })`,
    the button reading `Stopping…` after a click. The id is the prop, or the `id` of the first
    progress message; a stop clicked before any id is known is remembered and sent as soon as
    the first progress message brings the id. Under the button:
    `Stopping lets the assistants finish the turns they are on. You can carry on later.`
  - When a call ends (resolved or rejected) reload `panel({ id })` with the known id (from the
    prop, a progress message or the `PanelRan`), set `running` false, emit it. A rejection
    shows `failureMessage(error, 'The panel stopped before it finished. You can carry on from where it stopped.')`
    in an `alert-danger` (an `alert-info` with `Stopped. You can carry on from here.` when
    the person had pressed stop).
  - With a detail loaded: the question as a heading (plain text), `statusWords`, the seats'
    names joined by `, `, then the rounds: per round
    `Round {n}: how far apart they were, {d.toFixed(2)} (0 means they all agree).`, then per
    withheld seat `{seat}'s post was kept from the others: it had {findings mapped by
    findingWords, joined by ', '}.`, then when `failed` is not empty
    `Couldn't answer this round: {failed joined by ', '}.`
  - By status, when no call runs:
    - `paused` and `asked`: `How long may they take?` and one button per `TIME_LIMITS` entry
      whose value is not null → `resumePanel({ id, steer: null, timeBox: value }, onProgress)`.
    - `stopped`, `failed`, or `running` (on disk, not here): `Carry on` →
      `resumePanel({ id, steer: null, timeBox: null }, onProgress)`.
    - `closed`: `<PanelResult>` from `detail.result`, then `Ask them to reconsider` with a
      textarea `What should they think about again?` and a button `Reconsider` (disabled while
      the trimmed text is empty) → `resumePanel({ id, steer: trimmed, timeBox: null }, onProgress)`.
  - `Back to your panels` (link button, disabled while running) emits `back`.
- `builder/ui/src/screens/Panels.vue`: emits `running: [boolean]`. One of three views:
  - the list: heading `Panels`, the sentence `Ask several of your assistants one question. They
    work it out in rounds and come back with a joint answer, with any disagreement in full.`,
    button `Ask a new panel`, then `listPanels()` rows (loading `Loading your panels…`; empty
    `No panels yet.`; error via `failureMessage(…, "Your panels couldn't be read. Try again.")`),
    each row a button showing the question (plain text) and `statusWords(status, round)`, which
    opens `PanelRun` with that `id`;
  - `NewPanel`, whose `start` opens `PanelRun` with that `start`; `cancel` returns to the list;
  - `PanelRun`, whose `back` returns to the list and reloads it; it forwards `running`.
- `builder/ui/src/PersonaBuilder.vue`: a `'panels'` view. On the home view, after
  `<Assistants>`, a card with the heading `Panels`, the sentence above and a button
  `Ask a panel` → `view = 'panels'`. `<Panels v-else-if="view === 'panels'" @running="panelsRunning = $event" />`.
  `Your assistants` is disabled while `panelsRunning`, with
  `Stop the panel first to leave Panels.` shown as the build's sentence is. `home()` resets
  `panelsRunning`.
- `builder/ui/src/index.ts`: export `Panels`.
- `builder/ui/README.md`: add `panels` to "The screens so far".

## Plain text, never HTML (the security part)

- No `v-html`, `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `document.write`, no `:href`,
  `:src` or `:style` bound to panel data, and no markdown rendering, anywhere in
  `builder/ui/src` outside tests. Text only through `{{ }}` interpolation.
- A new test `builder/ui/src/plain-text.test.ts` scans every non-test `.ts` and `.vue` file under
  `builder/ui/src` (reuse `files`/`source` from `test-support.ts`, skipping `types/generated/`)
  and fails naming any file that holds `v-html`, `innerHTML`, `outerHTML`,
  `insertAdjacentHTML` or `document.write`.
