## Where this starts

The deliberation protocol moved out of voice into the shared repo `awna-ai/radio` (public, MIT). Its tag
`v0.1.0` (commit `03ee9562136875a0b1cfbbcc364a1f931612e469`) carries `crates/radio-panels`: voice's
`builder/panels` copied as one commit with **one** code change, already checked by `diff -r`:

- `radio_panels::Dissent` has `pub member: String` where `voice_panels::Dissent` has `pub crewmate: String`
  (so the serialized key is `member`); everything else in `src/` is identical (two generator comment lines
  name the new path). The rendered markdown is byte-identical.
- `radio-panels` depends on `regex = "=1.13.1"`, `serde = "=1.0.229"` (voice's lock already has both) and
  `serde_json = { version = "=1.0.151", features = ["preserve_order", "float_roundtrip"] }`: the same
  features `builder/panels` turns on, so JSON behaviour across the workspace does not change.
- The tag and serde_json 1.0.151 are already in this computer's cargo cache (`~/.cargo/git`,
  `~/.cargo/registry`).

Two crates use `voice_panels` today: `builder/api` (`src/ask.rs` uses `clean` and `fence`) and
`builder/panel-runner` (src and tests). Saved panels live under `~/.claude/voice/panels/<id>/`. A closed
panel's `result.json` is `SavedResult` (`builder/panel-runner/src/run.rs`, `#[serde(deny_unknown_fields)]`),
whose `dissent: Vec<voice_panels::Dissent>` is saved with the key `crewmate`. It is read back in two places:
`reopen_room` (resume of a closed panel) and the detail read (`room.read_json("result.json")`, then
`serde_json::to_value(result)` into `Detail.result`). `builder/api/src/panels.rs` `fn result` then reads
`entry["crewmate"]` from that value into `PanelDissent.seat`.

## Decisions (made; don't change them)

1. **The dependency.** In `builder/api/Cargo.toml` and `builder/panel-runner/Cargo.toml`, replace
   `voice-panels = { path = "../panels" }` with exactly
   `radio-panels = { git = "https://github.com/awna-ai/radio", tag = "v0.1.0" }` (https: the repo is public,
   so anyone builds voice without an SSH key; pinned by tag here and by commit in `Cargo.lock`).
2. **The crate leaves.** Remove `"builder/panels"` from the root `Cargo.toml` `members` and delete the whole
   `builder/panels/` folder (`git rm -r builder/panels`). Its tests and 66 fixtures now live and pass in the
   Radio repo; voice's own panel tests (below) are what proves the pinned crate here.
3. **Every `voice_panels` becomes `radio_panels`** in `builder/api` and `builder/panel-runner` (src and
   tests). Leave `builder/core/src/install_tests.rs`'s `voice_panels_survive_on_refresh_and_off` alone: it
   names the `~/.claude/voice/panels/` folder, not the crate. Don't touch `plans/briefs/` or `.ai/handoffs/`
   (history).
4. **`Cargo.lock`.** Let cargo rewrite it by building (`cargo build -p voice-panel-runner -p voice-api`);
   never a bare `cargo update`. If cargo refuses to move serde_json down on its own, run exactly
   `cargo update -p serde_json --precise 1.0.151`. The lock diff must be only: the `voice-panels` package
   gone, a `radio-panels 0.1.0` package with
   `source = "git+https://github.com/awna-ai/radio?tag=v0.1.0#03ee9562136875a0b1cfbbcc364a1f931612e469"`, the
   two dependents' lists naming it, and `serde_json` 1.0.154 → 1.0.151. Any other version change: stop and
   say which. If the resolver says some crate needs serde_json 1.0.152 or newer: stop and say which.
5. **Old saved results still load (no rewrite of anyone's files).** In `run.rs`, `SavedResult.dissent`
   becomes `Vec<SavedDissent>`, a private struct beside it:
   ```rust
   #[derive(Serialize, Deserialize)]
   struct SavedDissent {
       // Panels closed before the protocol moved to radio-panels saved this as `crewmate`.
       #[serde(alias = "crewmate")]
       member: String,
       holdout: bool,
       objections: String,
   }
   ```
   with `impl From<radio_panels::Dissent> for SavedDissent` used where `SavedResult` is built
   (`dissent: result.dissent.into_iter().map(Into::into).collect()`). No `deny_unknown_fields` on it
   (`voice_panels::Dissent` had none, so today's tolerance is kept); `SavedResult` keeps its own. New files
   are written with `member`; an old file is read as is and never written back by this change.
6. **The api reads `member`.** `builder/api/src/panels.rs` `fn result`: `entry["member"]` instead of
   `entry["crewmate"]` (the value always comes from `SavedResult` re-serialized, so it is always `member`
   now). `PanelDissent` and its `seat` field, the generated TypeScript type and the UI don't change.
7. **Docs.** `.ai/PROJECT.md`: delete the `builder/panels/` row; in the `builder/panel-runner/` row, after
   `(voice_panel_runner):` add `the protocol is radio_panels, from awna-ai/radio at tag v0.1.0;`.
   `.ai/SECURITY.md`, the row starting "A model's panel post forges the protocol's structure": its
   `` `voice_panels` reads only…`` becomes `` `radio_panels` (awna-ai/radio `v0.1.0`, pinned by tag and, in
   `Cargo.lock`, by commit) reads only…`` and, if that row's last column names `builder/panels/tests/`, it
   becomes `radio-panels' own tests in awna-ai/radio; here builder/panel-runner/tests/ and
   builder/api/tests/panels.rs`. Nothing else in the docs.
