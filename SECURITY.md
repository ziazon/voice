# Security and privacy

This kit reads people's private Claude Code history. If you find a way it could leak that history,
commit something personal, or write raw data outside the state folder, please report it privately
through GitHub's **Report a vulnerability** button on this repo (Security tab), not in a public issue.

Please include what you ran, what you expected, and what happened. Don't include anyone's real
history in the report; a fictional example is enough.
